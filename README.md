# competition-deck-templates

创赛 Deck 模板库 - 11 页标准骨架 + 叙事三元组 + 时间控制 + 视觉风格 + 参赛话术。

## Features

- **11 页标准骨架**: 封面 / 目录 / 问题 / 方案 / 功能 A / 功能 B / 创新 / 对比 / 实证 / 前景 / 团队
- **叙事三元组**: 每页 Takeaway（一句话）+ 关键要素
- **时间控制**: 8 分钟演讲 + Q&A 时间分配
- **视觉风格**: 暗色主题 + 配色 + 字体 + 间距（与 visualization-mcp v0.2.0 对齐）
- **参赛话术**: 开场 / 收尾 / Q&A 预案
- **数据真实性红线**: 禁止编造数字 / 虚构竞品 / 编造人物 / 渲染图冒充截图
- **参赛前 checklist**: 9 项检查清单

## Installation

直接克隆使用，无需安装：

git clone https://github.com/RuiChencc/competition-deck-templates.git
cd competition-deck-templates

## Quick Start

### 用 ppt-master 生成

把 preset 文档喂给 ppt-master，说：

"基于 presets/competition-deck-preset.md 生成一个创赛 PPT，项目名 ___, Slogan ___, 团队 ___"

### 手动创建

1. 用 PowerPoint / WPS 新建 16:9 空白模板
2. 按 presets/competition-deck-preset.md 的 P1-P11 结构复制
3. 按视觉风格表统一配色 / 字体
4. 按参赛前 checklist 逐项完成
