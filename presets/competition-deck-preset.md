# 创赛 Deck Preset v1.0.0

> **用途**：用户参加竞赛 / 黑客松 / 创新赛 / 创业路演时的可复用 PPT 骨架
> **使用**：喂给 ppt-master（Create Template 或 Generate PPTX route），或作为手写 PPT 的 checklist
> **作者**：RuiChencc ｜ **版本**：v1.0.0（2026-10-05）
> **配套**：visualization-mcp v0.2.0（K 线 / 决策树 / combo 图，dark 主题与下方视觉风格一致）

---

## 叙事主线（10 秒话术）

**"我用 ___ 解决 ___ 问题，用了 ___ 技术，实现了 ___ 效果。"**

---

## 页面骨架（11 页标准结构）

### P1 - 封面
- **标题**：项目名（大字号）
- **Slogan**：一句话价值主张（≤ 15 字）
- **副标题**：技术栈 + 团队 / 学校
- **视觉**：项目 logo（左）+ 暗色渐变背景（右）

### P2 - 目录
- **5 大板块导航**：问题 → 方案 → 演示 → 前景 → 团队

### P3 - 问题定义
- **痛点数据**（1 个关键数字）
- **典型场景**（1 个真实用户故事）
- **现有方案缺陷**（2-3 条，每条 ≤ 15 字）

### P4 - 解决方案概述
- **技术栈图**（架构示意图，3-5 层）
- **一句话架构**：输入 → 处理 → 输出
- **核心价值**（3 个 KPI）

### P5 - 核心功能 1
- **功能名**（动词开头）
- **演示截图**（1 张）
- **关键数据**（1 个数字）

### P6 - 核心功能 2
- 同 P5 格式

### P7 - 技术亮点 / 创新点
- **创新 1**（技术栈 / 算法 / 架构）
- **创新 2**（工程化 / 部署 / 成本）
- **创新 3**（用户体验 / 效率）

### P8 - 差异化对比
- **对比表**：本项目 vs 竞品 A vs 竞品 B
- **我们的护城河**（1 句话）

### P9 - 演示 / 实证
- **截图 3-5 张**
- **数据成果**（用户数 / 数据量 / 性能提升）

### P10 - 商业化 / 应用前景
- **市场空间**：TAM / SAM / SOM
- **商业模式**：B2B / B2C / Freemium
- **路线图**：3 / 6 / 12 个月里程碑

### P11 - 团队 / 联系
- **团队**（3-5 人 + 角色）
- **联系方式**：GitHub / Email / 微信

## 每页叙事三元组（模板）

| 页码 | 标题 | Takeaway | 关键要素 |
|---|---|---|---|
| P1 | 封面 | 项目定位 | 项目名 / Slogan / 团队 |
| P2 | 目录 | 讲述逻辑 | 5 板块导航 |
| P3 | 问题 | 用户痛点严重 | 1 数字 / 1 故事 / 3 缺陷 |
| P4 | 方案 | 我们如何解决 | 架构图 / 3 KPI |
| P5 | 功能 A | 核心能力 1 | 演示 / 数据 |
| P6 | 功能 B | 核心能力 2 | 演示 / 数据 |
| P7 | 创新 | 差异化技术 | 3 创新点 |
| P8 | 对比 | 我们更强 | 对比表 / 护城河 |
| P9 | 实证 | 已验证 | 截图 / 数据 |
| P10 | 前景 | 可商业化 | TAM / 商业模式 / 路线图 |
| P11 | 团队 | 可联系 | 团队 / 联系方式 |

## 视觉风格（与 visualization-mcp v0.2.0 对齐）

- **主色**：#1a1a2e（背景）+ #ef5350（强调）
- **辅色**：#42a5f5（蓝）/ #66bb6a（绿）/ #ffa726（橙）
- **字体**：思源黑体 / 微软雅黑
- **图表**：visualization-mcp v0.2.0
- **间距**：页边距 60px，标题与内容间距 30px
- **字号**：标题 44pt / 副标题 28pt / 正文 18pt / 备注 14pt
